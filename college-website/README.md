# Techno Valley College - 3D College Website

A complete multi-page college website with 3D hero section built using HTML, CSS, JavaScript, and Three.js.

## Features

- **7 Pages:** Home, About, Courses, Admissions, Facilities, Gallery, Contact
- **3D Hero Section:** Rotating 3D college building with Three.js
- **Responsive Design:** Works on mobile, tablet, and desktop
- **Interactive:** Course filters, contact/admission forms, scroll animations
- **Modern UI:** Clean design with Font Awesome icons

- JavaScript (Vanilla)

## How to Run

1. Clone or download this repository.
2. Open `college-website/index.html` in any modern web browser.
3. For the 3D hero section to work, an internet connection is needed (loads Three.js from CDN).
